# FinTrack Pro — Personal Finance Tracker

A complete personal finance system backed by Google Sheets.

## Live App
👉 [Open FinTrack Pro](https://YOUR_USERNAME.github.io/fintrack/)
👉 [Open Bulk Importer](https://YOUR_USERNAME.github.io/fintrack/importer.html)

## Features
- Track all bank accounts, credit cards and loans
- Record income, expenses, transfers and EMIs
- Investment portfolio (SIP, NPS, PPF, Gold, Stocks)
- Budget vs actuals by category
- Account reconciliation
- Net worth dashboard
- Bulk import from bank statements

## Setup
1. Connect to your Google Sheet via Apps Script
2. Add your accounts
3. Start tracking
