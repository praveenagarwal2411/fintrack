FinTrack Pro

Your complete personal finance system — all accounts, transactions, investments & net worth in one place, backed by your Google Sheet.

1
Open Google Sheets → create a blank spreadsheet → name it "FinTrack"
2
Click Extensions → Apps Script → delete all code → paste contents of Code.gs → Save
3
Click Deploy → New deployment. Click the gear icon → select Web app. Set:
• Execute as: Me
• Who has access: Anyone
Click Deploy → allow permissions → copy the Web app URL (ends in /exec)
4
Important: After any code change, always do Deploy → Manage deployments → Edit (pencil) → Version: New version → Deploy. Re-using an old version will not pick up changes.
5
Paste the URL below and tap 🔍 Test URL first — you should see {"ok":true} in the new tab. Then tap Connect.
